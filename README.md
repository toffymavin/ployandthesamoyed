# Ploy & the Samoyed

เกมเลี้ยงน้องซามอยด์ เปิดที่ GitHub Pages

## อยากแก้อะไร เปิดไฟล์ไหน

| อยากแก้ | ไฟล์ |
|---|---|
| คำพูดของน้อง (ลูบหัว, ทักทาย, หิว, ง่วง ฯลฯ) และจดหมาย | `js/content.js` |
| ข้อความจาก Top / ข้อความในขวด | `messages.json` |
| เมือง, ของตกแต่ง, ท่าทาง, ข้อความรายวัน, เพื่อนหมา | `js/world-data.js` |
| สี ฟอนต์ ขนาดปุ่ม | `style.css` |
| ปุ่มและหน้าตาในหน้าเว็บ | `index.html` |
| วาดน้องหมาและชุด | `js/dog.js` |
| ห้อง, ขนที่ร่วง | `js/scene.js` |
| เสียงและเพลง | `js/sound.js` |
| ให้อาหาร เล่น อาบน้ำ นอน + หน้าต่างเมนู | `js/actions.js` |
| กลางวัน/กลางคืน, ของแต่งห้อง, เพื่อนมาเยี่ยม | `js/room.js` |
| โหมดบิน | `js/flight.js` |
| สอนท่า, แปรงขน | `js/tricks.js` |
| อัลบั้มรูป, ร้านค้า | `js/album-shop.js` |
| ภาพสแตมป์ของแต่ละเมือง | `js/city-art.js` |
| คุกกี้เสี่ยงทาย, อากาศ, ลูกหมา, คู่มือเปิดครั้งแรก | `js/extras.js` |
| สถานที่เดินเล่น | `js/places.js` และ `js/walk-extras.js` |
| ของในบ้าน, ส่งขึ้นเครื่อง, ตอนจบ | `js/home.js` |
| ข้อความจาก Top, ไดอารี่ตอนไม่อยู่, เช็กอิน | `js/messages.js` |
| มินิเกม | `js/games/` (เกมละไฟล์) |
| ลากเป็ด Sunny, Add to Home Screen, รหัสสำรอง | `js/duck-backup.js` |
| กดปุ่มแล้วเกิดอะไรขึ้น | `js/events.js` |
| สิ่งที่ทำตอนเปิดเกม | `js/start.js` |
| แจ้งเตือน ntfy | `js/notify.js` |

## ข้อควรรู้

- ไฟล์ JS โหลดตามลำดับที่เขียนไว้ใน `index.html` ไฟล์หลังใช้ของที่ประกาศในไฟล์ก่อนหน้าได้ ถ้าเพิ่มไฟล์ใหม่ ให้ใส่ `<script src="...">` ใน `index.html` ก่อนบรรทัด `js/events.js`
- ทุกครั้งที่เพิ่มหรือเปลี่ยนชื่อไฟล์ ให้แก้รายชื่อใน `sw.js` ด้วย แล้วเปลี่ยน `samoyed-v8` เป็นเลขถัดไป มือถือจะได้โหลดของใหม่
- เปิดเกมด้วย `?me=1` ต่อท้ายลิงก์ เครื่องนั้นจะไม่ส่งแจ้งเตือน ntfy
